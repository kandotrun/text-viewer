# 読むだけ

[viewer.2-38.com](https://viewer.2-38.com/) を開いて、読みたい文章を貼り付けるか入力します。
ヒラギノ優先の26pxで文章を表示し、その場で編集やコピーができます。
スマートフォンではページを長押しして貼り付けられます。

入力した文章は「リンクをコピー」で共有できます。
本文をブラウザーで圧縮・暗号化してから保存するので、公開先で作る共有リンクは本文の長さにかかわらず55文字です。
復号鍵はリンクの `#` 以降に入り、受け取った人のブラウザーで本文を復元します。
作成から7日でリンクは失効し、共有用ストレージから暗号文を自動削除します。
Cloudflare Durable Objects の障害復旧機能は、過去30日間の状態を復元できる仕様です。
以前に作った、本文をURL内に含むリンクも引き続き開けます。

再読み込みや履歴からページを開き直すと、入力欄が空になります。

## 開発と公開

```sh
npx wrangler dev --local
npx wrangler deploy --dry-run
```

ブラウザーでの回帰テストは `npm ci` と `npx playwright install chromium` のあと、`npm test` で実行できます。

`public/` の静的ファイルを Cloudflare Workers に配信し、共有リンク用の暗号文を Durable Objects に保存します。
`2-38.com` ゾーンを管理する Cloudflare アカウントで `npx wrangler deploy` を実行すると、設定済みのカスタムドメインに公開できます。
